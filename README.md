# Yantra

Yantra is a Windows-native autonomous software engineering platform that coordinates specialised AI agents to plan, design, build, test, verify, package, deploy, and maintain software from a unified engineering workspace.[cite:18]

Yantra is not a chat wrapper, editor clone, or code-completion tool. It is being built as an engineering operating system where missions, agents, workspace state, capabilities, memory, and verification are first-class product concepts.[cite:18][cite:30]

## Product direction

Yantra is now transitioning from architecture-first foundation work to product-first execution. The engineering substrate remains important, but the next major priority is turning that foundation into a usable Windows product with a real application shell, workspace experience, mission surfaces, agent visibility, settings, packaging, and installer delivery.[cite:18][cite:21]

## Current transition

The project has reached a genuine transition point:

- Stage 1 — Engineering Foundation: largely established.
- Stage 2 — Product Foundation: next priority.
- Stage 3 — Autonomous Engineering: differentiated product value.
- Stage 4 — Production Platform: later expansion into collaboration, remote agents, cloud sync, and enterprise capabilities.[cite:18]
