# Yantra

- `01_FOUNDATION/` — enduring project identity and principles
- `02_SPECIFICATIONS/` — canonical runtime specifications
- `03_IMPLEMENTATION/` — generated/maintained implementation contracts
- `04_GOVERNANCE/` — compliance, certification, validation, readiness, CI governance
- `.ai/` — AI bootstrap instructions and canonical agent loading order
- `missions/` — mission packs
- `knowledge/` — accumulated engineering knowledge
