# Readiness

Readiness documentation records whether the repository, a subsystem, or a phase is prepared to move forward.

## Expectations

Readiness should be judged against:

- canonical requirements,
- architecture alignment,
- verification status,
- documentation completeness,
- known risks and unresolved dependencies.
