# Quality Gates

Quality gates define the minimum repository and change conditions required before work is considered ready to merge, release, or certify.

## Gate categories

- Product alignment
- Architecture alignment
- Verification evidence
- Documentation currency
- Security and boundary safety
- Release readiness

## Expectations

Each gate should be explicit, reviewable, and tied back to canonical product and architecture intent. Gates are not advisory notes; they are decision points that block unsafe or incomplete work.
