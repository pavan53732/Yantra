# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) for significant architectural decisions made during the development of Yantra.

## What is an ADR?

An Architecture Decision Record is a short text file that describes a significant architectural decision made along with its context and consequences.

2. Replace the placeholder text with your ADR content
