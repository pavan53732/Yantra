# Schemas

Structured schemas (JSON Schema / TypeScript types) for the core data objects
that flow through Yantra: Missions, Events, Agent Tasks, and Artifacts.

## Contents

- `mission.schema.json` — Mission object shape *(coming soon — Phase 2)*
- `event.schema.json` — Event envelope shape *(coming soon — Phase 2)*
- `agent-task.schema.json` — Agent Task shape *(coming soon — Phase 2)*
- `artifact.schema.json` — Artifact shape *(coming soon — Phase 2)*

See [`docs/specifications/01_FOUNDATION/MISSION.md`](../specifications/01_FOUNDATION/MISSION.md) for the
conceptual Mission lifecycle these schemas formalize.
