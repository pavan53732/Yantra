# Decisions Log

This directory tracks product and scope decisions that are not architectural
enough to warrant an Architecture Decision Record (see [`docs/adr/`](../adr/))
but still need a durable record of what was decided and why.

## What Goes Here vs. ADR

- **ADR** (`docs/adr/`): decisions about system architecture, invariants,
  technology choices with long-term structural consequences.
- **Decisions** (here): product scope, prioritization, naming, and other
  calls that affect direction but not architecture.

## Contents

*Decisions will be logged here as they are made, starting in Phase 1 (Product
Definition).*
