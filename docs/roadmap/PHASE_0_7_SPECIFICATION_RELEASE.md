# Phase 0.7 — Specification Release

This phase converts the spec set into a release artifact.

## Deliverables

- v1.0.0 specification set
- specification changelog
- architecture baseline
- machine-readable schemas
- protocol definitions
- validation report
- architecture approval
- implementation authorisation

## Rules

- Every frozen spec receives a semantic version.
- Any change to a frozen spec requires a decision record.
- The spec set is treated as an API.
