# Phase 1 — Product Definition

**Goal:** Define what Yantra must do before defining how it is built.

## Scope

- Finalize `MISSION.md` as the canonical unit of work.
- Define target users and primary Mission types (e.g., "build a feature," "fix a bug," "refactor a module," "write tests").
- Define `SYSTEM_INVARIANTS.md` and `FAILURE_MODEL.md` as binding constraints on every subsequent phase.
- Define success metrics for a Mission (completion rate, verification pass rate, human intervention rate).

## Exit Criteria

- Product Definition document approved and referenced by all specifications going forward.
