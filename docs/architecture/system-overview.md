# System Overview

Yantra is a Windows-first autonomous software engineering product composed of a workspace shell, mission workflow, specialised agents, memory and knowledge support, provider integration, and verification surfaces.

## Core domains

- Workspace
- Missions
- Agents
- Providers
- Memory
- Knowledge
- Verification
- Governance

## Architectural intent

These domains must work together as one governed engineering system. The product should remain mission-first, verification-aware, and suitable for long-running desktop workflows.

## Verification expectations

The system overview should stay aligned with the PRD, roadmap, and the detailed architecture documents for each core domain.
