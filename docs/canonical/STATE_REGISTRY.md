# State Registry

Canonical lifecycle states for Yantra subsystems.

## Mission States
Created, Planning, Waiting, Executing, Paused, Resuming, Verifying, Completed, Archived, Blocked, Cancelled, PartiallyCompleted

## Agent States
Spawning, Idle, Busy, Terminating, Terminated, Crashed

## Tool States
Requested, Running, Succeeded, Failed, TimedOut, Cancelled

## Plugin States
Registered, Enabled, Disabled, Crashed

## Provider States
Registered, Healthy, Degraded, Unavailable

## Workspace States
Clean, Dirty, Snapshotting, Snapshotted, RolledBack
