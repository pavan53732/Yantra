# Event Registry

Canonical event names and owners.

## Rules

- Every event has one publisher and one owning subsystem.
- Events are immutable and versioned.

## Canonical Events

- MissionCreated
- MissionPlanned
- MissionStarted
- MissionPaused
- MissionResumed
- MissionCompleted
- TaskAssigned
- TaskStarted
- TaskCompleted
- TaskFailed
- ToolRequested
- ToolFinished
- ToolFailed
- AgentSpawned
- AgentCrashed
- MemoryUpdated
- MemoryConflict
- VerificationPassed
- VerificationFailed
- ProviderFailed
- PluginCrashed
