# Error Registry

Canonical error taxonomy.

Format:
DOMAIN.CATEGORY.CODE

## Domains
- AI_PROVIDER
- MEMORY
- PLUGIN
- MISSION
- TERMINAL
- TOOL
- IPC
- PLANNER
- VERIFIER
- SECURITY

## Examples
- AI_PROVIDER.TIMEOUT
- MEMORY.CORRUPTION
- PLUGIN.INVALID_SIGNATURE
- MISSION.INVALID_STATE
- TERMINAL.PROCESS_DIED
- TOOL.INVALID_ARGUMENTS
- IPC.UNAUTHORIZED
- PLANNER.UNSATISFIABLE_CONSTRAINTS
- VERIFIER.INCONCLUSIVE
