# Desktop Application

The Electron-based desktop application for the Yantra platform.

## Structure

```
apps/desktop/
├── src/
│   ├── main/           # Electron main process
│   ├── renderer/       # React renderer process
│   └── preload/        # Preload scripts
├── assets/             # App icons and assets
├── package.json
└── tsconfig.json
```
